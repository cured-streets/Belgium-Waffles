# Location Bible

## Primary Location: Farmhouse Kitchen

A warm rustic farmhouse kitchen with a coherent layout maintained across all major shots.

## Required Elements

- Large wooden preparation counter
- Vintage stove
- Farmhouse sink
- Cast-iron cookware
- Ceramic mixing bowls
- Waffle iron
- Open shelves
- Pastel kitchen details
- Large windows with golden morning light
- Dust or flour visible in sunbeams

## Layout Lock Checklist

- [ ] Wide establishing view
- [ ] View toward stove
- [ ] View toward preparation counter
- [ ] Reverse angle
- [ ] Window-light direction
- [ ] Prop-placement guide
